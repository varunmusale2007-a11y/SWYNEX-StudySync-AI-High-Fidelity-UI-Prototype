# StudySync AI — High-Fidelity UI & Prototype

## Overview

StudySync AI is an AI-powered study planning and productivity
platform designed to help students organize their studies,
manage schedules, track progress and receive AI-powered study
assistance.

## SWYNEX Internship — Task 3

This project was completed as part of Task 3 of my internship
at SWYNEX Technologies.

The objective was to transform the low-fidelity wireframes
from Task 2 into a polished high-fidelity UI and interactive
prototype.

## Screens

- Login / Sign Up
- Student Onboarding
- Add Subjects
- Dashboard
- Study Planner
- My Subjects
- Today's Schedule
- Study AI
- Calendar
- Progress / Analytics
- Profile / Settings

- Figma

- Interactive Prototyping
